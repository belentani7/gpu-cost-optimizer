# ADR-001 — Keep estimation offline and ship a static calculator

## Status

Accepted for this product iteration.

## Context

The canonical product prompt defines GPU Cost Optimizer as an offline estimation tool. Current Python heuristics and reference tariffs are deterministic and require no credentials, but the deployed page is not an interactive product. A hosted API or live pricing integration would add external data and change the product boundary.

## Decision

Keep Python as the canonical model and deployment dependency. Add a static browser calculator that mirrors its versioned formulas and works without network access. Treat tariff rows as historical references and clearly identify simulated timing/VRAM.

## Consequences

- Users can try the product in a browser without installing Python.
- The frontend duplicates model formulas; parity fixtures and a visible model version are required.
- No current pricing, cloud availability, measured quality, or actual GPU performance is claimed.
- Existing package/CLI users retain their offline workflow.
